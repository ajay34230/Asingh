# Asset and licence manifest

Phase 1 uses **no external assets**. Everything visible is generated in code from Godot's built-in primitive meshes and procedural noise; there are no imported textures, models, fonts, audio or music.

| Item | Source | Author | Licence | Attribution required | Local path | Modifications |
| --- | --- | --- | --- | --- | --- | --- |
| Terrain, mountains, ruins, entrance, statues, symbols, disc | Generated by GDScript at runtime | Project code | Project's own | No | `scripts/*.gd` | n/a |
| App icon | Hand-written SVG | Project | Project's own | No | `icon.svg` | n/a |
| On-screen text (FPS, hint, button labels) | Godot's built-in fallback font | Godot Engine contributors | See Godot licence | See below | engine built-in | none |

## Rules for future phases

- Record every added asset here with name, source URL, author, licence, attribution text, local path and modifications.
- Only use original work, public-domain / CC0 material, or assets whose licence permits this use. No assets ripped from commercial games.
- Do not commit APKs, keystores, SDKs or passwords.

## Audio added in Phase 1 (all generated, no third-party samples)
- `assets/audio/*.wav` sound effects and ambience: `tools/make_audio.py` (CC0, own work).
- `music_race/tension/sacred/mystery.wav` and `sting_*.wav` (surprise, discovery, victory, sad, danger, reveal): `tools/make_music.py` (CC0, own work).
- `assets/voice/*.ogg` spoken dialogue: rendered offline with the **Kokoro-82M** neural TTS model (Apache-2.0; ONNX build from github.com/thewh1teagle/kokoro-onnx releases) and phonemes from **espeak-ng** (GPL-3.0, used only as a build-time tool; no espeak code ships in the game). Script: `tools/render_voices.py`; lines come from `tools/voice_lines.py`. Models and binaries are not committed.
- Market sounds (`market_crowd_loop`, `street_murmur_loop`, `water_splash_loop`, `sizzle_loop`, `fire_crackle_loop`, `music_bazaar`, `scrub`, `sweep`, `chop`, `knead`, `pot_clink`, `coin_clink`, `tink`, `cloth_flap`, `goat_bleat`, `hen_cluck`, `child_laugh`, `cart_creak`, `bicycle_bell`) and `deer_call`, `animal_pain`, `animal_thud`: `tools/make_market_audio.py` and inline synthesis (CC0, own work).

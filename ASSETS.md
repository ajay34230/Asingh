# Asset and licence manifest

Phase 1 uses **no external assets**. Everything visible is generated in code from Godot's built-in primitive meshes and procedural noise; there are no imported textures, models, fonts, audio or music.

| Item | Source | Author | Licence | Attribution required | Local path | Modifications |
| --- | --- | --- | --- | --- | --- | --- |
| Terrain, mountains, ruins, entrance, statues, symbols, disc | Generated by GDScript at runtime | Project code | Project's own | No | `scripts/*.gd` | n/a |
| App icon | Hand-written SVG | Project | Project's own | No | `icon.svg` | n/a |
| On-screen text (FPS, hint, button labels) | Godot's built-in fallback font | Godot Engine contributors | See Godot licence | See below | engine built-in | none |

## Rules for future phases

- Record every added asset here with name, source URL, author, licence, attribution text, local path and modifications.
- Only use original work, public-domain / CC0 material, or assets whose licence permits this use. No assets ripped from commercial games.
- Do not commit APKs, keystores, SDKs or passwords.

# Privacy Policy: The Lost Kingdom

Last updated: 2026-11-15

**The Lost Kingdom** is a single-player game. You can play it fully offline.

## What the game does not do
- It does **not** collect, store, transmit or share any personal information.
- It has **no** accounts, analytics, advertising, in-app purchases or third-party SDKs.
- It does not ask for camera, microphone, location, contacts or storage access.

## Internet use: optional character downloads
- Some extra playable characters and heavy monster models are not inside the app. When you choose one, or a mission needs one, the game asks first and then downloads the model file over HTTPS from GitHub (`raw.githubusercontent.com`).
- The game sends no personal data with these downloads. Like any web request, GitHub receives your device's IP address and basic request details to deliver the file. GitHub's own privacy statement covers how it handles that: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
- Downloaded files are stored inside the game's own storage on your device. You can remove them from the in-game character menu, and they are deleted when you uninstall the game.
- If you never download a character, the game makes no internet connections.

## Data on your device
- Saved progress and settings stay on your device and are removed when you uninstall the game.
- The game keeps a small diagnostic log on your device to help fix crashes. It never leaves your device unless you choose to copy it or save it to a file yourself (from the in-game "Crash & logs" screen) and send it to someone.

## Permissions
- Internet: only for the optional downloads above.
- Vibration: for controller-style feedback during play.

## Children
The game is not designed for children under 13. It contains no ads, purchases or online play.
